## Try it

Choose a palette, change scale, and pause the animation to inspect the result. Use the arrow keys on any focused slider for precise adjustments.

## Code

Initial configuration. The controls above change the preview.

```jsx MeshGradient.jsx
import { MeshGradient } from '@paper-design/shaders-react';

export function ShaderExample() {
  return (
    <div style={{ width: '100%', height: 420 }}>
      <MeshGradient
        width="100%"
        height="100%"
        maxPixelCount={2000000}
        speed={0.45}
        scale={1}
        rotation={0}
        colors={["#1b0a3d","#7251ff","#f25dbb","#dac9ff"]}
        distortion={0.8}
        swirl={0.35}
        grainMixer={0}
        grainOverlay={0}
      />
    </div>
  );
}
```

## Parameters

`distortion` folds the color field, while `swirl` rotates its flow. Lower the speed for a quiet background; increase scale to crop into the pattern.

The canvas is WebGL; the controls are authored for this demo. See the [package reference](https://shaders.paper.design/mesh-gradient).
