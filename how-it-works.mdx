## Add a package

Paper Shaders is one example of the same import flow.

<Steps>
  <Step title="Install the package">
    ```bash
    pnpm add --save-exact @paper-design/shaders-react@0.0.81 react@19.2.3 react-dom@19.2.3
    ```
  </Step>
  <Step title="Enable package imports">
    Add `"packages": {}` to `docs.json`. Keep `package.json` and the lockfile alongside it.
  </Step>
  <Step title="Import a component in a snippet">
    ```jsx
    import { MeshGradient } from '@paper-design/shaders-react';

    export function Example() {
      return <MeshGradient width="100%" height={420} colors={['#5100ff', '#00ff80', '#ffcc00']} />;
    }
    ```
  </Step>
  <Step title="Start the local preview">
    ```bash
    MINTLIFY_NATIVE_NPM_PACKAGES=1 mint dev --port 3344
    ```
  </Step>
</Steps>
